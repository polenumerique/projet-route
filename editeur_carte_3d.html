Éditeur de carte 3D

Toute la carte du jeu vient d'ici : plus de génération procédurale. Place le point de départ, dessine les routes, les portes (magasins, planque, hôpital, garage…), les places de parking, les zones où les piétons flânent, puis tes bâtiments/décors. Exporte carte.json à côté du jeu.
Point de départ du joueur

Clique sur le sol pour placer (ou déplacer) le point de départ.

Routes

Clique sur le sol pour ajouter des points à la route en cours. « Nouvelle route » en démarre une autre.

Portes

Configure puis clique sur le sol pour placer une porte.

Places de parking

Clique sur le sol pour poser une place (voitures garées / trafic qui se gare).

Zones de flânerie (piétons)

Clique sur le sol pour poser une zone où des piétons se promènent.

Bibliothèque de modèles

Sélectionne un modèle puis clique au sol pour le placer.
